# ZestBotz Solutions — Official Website

**Transforming workflows through AI-driven Automation and Analytics.**

The official website of **ZestBotz Solutions Pvt. Ltd.**, an IT services and consulting company focused on intelligent automation, AI-powered solutions, data analytics, and software development.

The website showcases the company's services, industry solutions, and technology capabilities through a modern, responsive user interface.

## Overview

ZestBotz Solutions helps businesses explore technology-driven approaches to improving workflows, automating repetitive processes, and making better use of data.

This project presents the company's digital presence, including its service offerings, industry-specific solutions, company information, and contact pathways.

## Services Featured

- **Process & Workflow Automation** — Streamlining repetitive tasks and business processes.
- **Agentic AI Solutions** — Exploring AI-driven systems for task execution and workflow orchestration.
- **Web Scraping & Data Solutions** — Collecting and organizing web-based data for business use cases.
- **Web & Software Development** — Building websites and software applications.
- **Data Analytics** — Turning data into meaningful insights for decision-making.
- **ERP Solutions** — Supporting enterprise resource planning and business operations.
- **Healthcare RCM** — Technology solutions for healthcare revenue cycle management.
- **Chatbot Integration** — Integrating conversational interfaces into digital workflows.

## Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Routing:** React Router DOM
- **Language:** JavaScript (JSX)
- **Version Control:** Git and GitHub

## Features

- Responsive design for desktop, tablet, and mobile devices.
- Dedicated pages for services and industry solutions.
- Reusable React components.
- Client-side navigation using React Router.
- Consistent branding, typography, and visual styling.
- Contact pathways for business enquiries.
- Modern layouts with gradients, interactive elements, and service-focused content.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/yaswanth-swargam/ZestBotz-Solutions.git
```

**2. Navigate to the project directory**

```bash
cd ZestBotz-Solutions
```

**3. Navigate to the frontend**

```bash
cd Frontend
```

**4. Install dependencies**

```bash
npm install
```

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Customization

To modify the website:

- **Pages:** Update the relevant files in `src/pages/`.
- **Service pages:** Update the components in `src/pages/services-page/`.
- **Reusable components:** Modify the components in `src/components/`.
- **Layout:** Update shared navigation and footer elements in the layout components.
- **Styling:** Customize Tailwind CSS classes and the relevant CSS files.
- **Routing:** Update route definitions in `src/App.jsx`.

## Deployment

The production build can be deployed to a static hosting platform that supports Vite applications, such as:

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)

Configure the deployment settings according to the repository's actual folder structure and build configuration.
